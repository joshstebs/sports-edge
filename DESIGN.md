# SportsEdge design contract

SportsEdge is a sports research desk. Preserve the existing ink surfaces, mint action color, off-white text and SportsEdge mark. Distinction comes from the research workflow and visible evidence, not an unrelated visual rebrand.

- Use left-aligned headings, clear table columns and tabular figures. Expose the selection before supporting metadata.
- Keep research forms and quote scenarios readable, with 44px input targets and visible keyboard focus. Use borders and spacing before extra containers.
- Use the established semantic tokens in `src/index.css`. No decorative gradients, sparkle icons, fake telemetry, fabricated picks or activity counters.
- Show loading, unavailable and empty states explicitly. Separate no filter matches from an empty recommendation feed.
- Put quote limitations, historical sample counts and push handling beside their values. Never label a stored recommendation as a live sportsbook price.
- Apply the user's October 21 Web & App Design Playbook. Use the IMPACT award-winning design article as inspiration for readable navigation, useful configurators and honest data presentation, rather than copying layouts.

New research and scenario code must remain lazy-loaded with its destination. Preserve chat, voice, ledger, model evaluation, all supported sports and both themes.
